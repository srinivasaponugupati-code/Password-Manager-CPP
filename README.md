
# Password Manager Using C++

## Project Overview
A console-based Password Manager developed using
C++ and Object-Oriented Programming concepts.

## Features
- Add account credentials
- View saved accounts
- Search accounts by website
- Delete saved accounts
- Menu-driven interface

## OOP Concepts Used
- Classes and Objects
- Encapsulation
- Constructors
- Abstraction

## Technologies
- C++
- STL Vector
- GitHub

## How to Compile
```bash
g++ -std=c++17 main.cpp -o password_manager
```

## How to Run
```bash
./password_manager
```

## Future Enhancements
- Master password authentication
- Persistent file storage
- Encrypted password storage
